Rclone Google Drive Authentication

This application provides Google OAuth 2.0 authentication for use with Rclone, an open-source file synchronization and cloud storage tool.

Purpose

The application allows authorized users to connect Rclone to their Google Drive accounts and perform file operations according to their configured permissions.

How It Works

Authentication is performed through Google's secure OAuth 2.0 authorization process. Users explicitly approve the requested Google Drive permissions and may revoke access at any time.

Data Access

Google Drive access is limited to the permissions granted during authorization. File transfers and synchronization are managed by Rclone according to the user's configuration.

Privacy

For information about data access, storage, and user control, see our Privacy Policy.

This is an independently configured OAuth integration and is not affiliated with Google or the Rclone project.
